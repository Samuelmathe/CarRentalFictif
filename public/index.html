Roulez moderne avec AutoLoc

Flotte variée, tarifs clairs et parcours en ligne — démo technique HTML, CSS, JavaScript, Express et SQLite.

Pourquoi AutoLoc ?

  • Offres adaptées Du citadin compact au SUV familial, avec filtres et tri en temps réel.
  • Données côté serveur Le catalogue est servi par une API REST ; la base SQLite peut être remplacée par PostgreSQL ou MySQL en production.
  • Réservation démo Formulaire relié au backend pour montrer le flux complet (sans paiement réel).
  • Compte & session Inscription, connexion (cookie de session httpOnly) et historique de vos demandes.
  • Back-office Rôle administrateur : gérer le catalogue et le statut des réservations.

À propos

Ce site est une démo pédagogique de location en ligne : interface moderne, API Node (Express) et persistance SQLite.

Ce que montre le projet

  • Front statique servi par Express (public/)
  • API REST : catalogue, réservations, authentification, espace client, admin
  • SQLite : utilisateurs (mot de passe hashé), véhicules, réservations avec statut

Compte démo admin : admin@autoloc.demo / AdminDemo2026! — à changer en production.

Aucune entreprise réelle — idéal pour portfolio ou base vendable sur ComeUp après personnalisation.
